# Screenshots

Actual application captures from October 29, 2026, using Chromium with WebGL
against the static build and shipped content security policy. These are
synthetic examples, not customer models or manufacturing acceptance evidence.

- `compare.png`: two original synthetic flanged mounting sleeves, with baseline
  height 28 mm/body radius 15 mm and candidate height 33 mm/body radius 17 mm.
  The flanges and central bore make the difference visible in all three views.
- `inspect.png`: the candidate sleeve, 46 × 46 × 33 mm, with 1,152 triangles.
- `homepage.png`: the landing page and its built-in example.

The [sleeve geometry and generator](../examples/README.md) were created for this project and is available under
this repository's MIT license. Screenshots show real computed results;
sampling limits still apply. No external model assets were used.
